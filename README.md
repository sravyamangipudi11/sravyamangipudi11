## 🚀 Featured Projects

### [🧾 AI-Powered Invoice Processing Validation (ASA Invoice Engine)](https://github.com/sravyamangipudi11/asa-invoice-engine)

* Extracts data from PDF/scanned invoices and automates **PO matching, duplicate detection, tax validation**, and **APPROVE / REVIEW / REJECT** decisions.
* Auditable **8-check deterministic decision engine** handling split POs, tax-inclusive invoices and deduplication, validated with regression tests.
* **Streamlit** dashboard with run analytics, extraction caching, LLM fallback and API-error handling. Stack: Python, Gemini API, SQLite.

### [🔎 Search Your PDF (RAG-based Q&A)](https://github.com/sravyamangipudi11/search-your-pdf)

* Natural-language querying over user-uploaded PDFs using **LangChain**, **Hugging Face** embeddings and **ChromaDB** similarity retrieval.
* **FastAPI** backend combines retrieved context with user queries for on-demand LLM answers.

### [📈 Macro-Risk Aware Hybrid Deep Learning for Financial Market Forecasting (BTP)](https://github.com/sravyamangipudi11/stock-price-prediction)

* Built a forecasting pipeline over **117K+ observations from 28 BSE large-cap firms**, combining returns, momentum, volatility, and macro-risk signals (**GARCH(1,1), GPR, FSI**).
* Designed a **CNN-LSTM-GRU** architecture tuned with the **Whale Optimization Algorithm**, benchmarked against **six baseline models** under a strict no-test-leakage evaluation.
* Integrated OHLCV data, financial news, **FinBERT** sentiment and **Gemini** embeddings, with PCA and trading-day alignment to prevent look-ahead bias.
* Being prepared for academic publication.

### [🧪 A/B Testing on Digital Marketing Campaigns](https://github.com/sravyamangipudi11/A-B-testing-project)

* End-to-end analysis: cleaning, feature engineering, and **CTR, CVR, CPC, CPP** metrics.
* Used **Welch's t-tests** to find statistically significant improvements in click-through rate, with visual recommendations to optimize strategy and ROI.

### [🏦 Customer Churn Analysis & Prediction](https://github.com/sravyamangipudi11/Bank-Customers-Churn-Prediction)

* Analyzed **10K customer records**; engineered features such as balance-to-salary, tenure-to-age and credit-score-to-age ratios to find high-risk segments.
* Compared Logistic Regression, SVM, Random Forest and XGBoost; **Random Forest reached 80% precision and 39% recall** on unseen data.

### [☕ Coffee Shop Sales Dashboard](https://github.com/sravyamangipudi11/Coffee-shops-sales-dashboard)

* Ran **20+ MySQL queries** on a **149K-row** transactional dataset for cleaning and aggregation.
* Built an interactive **Power BI** dashboard (KPIs, slicers, calendar heatmaps, hourly tooltips) analyzing sales by product, store and weekday/weekend.
